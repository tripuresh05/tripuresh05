## 💻 Software / CSE Projects

<details open>
<summary><b>🎮 Clash of Crowns — 3D Chess App</b></summary>
<br/>

High-performance 3D chess app with 360° camera controls, dynamic lighting, and 4 board themes. Features a self-built hybrid **Negamax AI** (alpha-beta pruning, PVS, transposition tables) combined with **Stockfish 10 WASM** for difficulty up to 2800+ Elo. Real-time moves powered by Socket.io, with Firebase Auth/Firestore for progress tracking.

**Tech:** React · Three.js · TypeScript · Stockfish WASM · Firebase · Socket.io · Tailwind CSS

</details>

<details open>
<summary><b>📚 Batchify — CBT Prep Platform</b></summary>
<br/>

Gamified EdTech platform for exam prep and Previous Year Questions (PYQ). Supports subjective-answer photo uploads to Cloudinary with canvas compression and rotation controls, plus a Firestore-synced XP progress ledger with background reconciliation and flexible sequence-unlocking.

**Tech:** React & Next.js · Cloudinary API · Firebase & Firestore · Tailwind CSS · Framer Motion

</details>

</details>
